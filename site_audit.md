# Аудит сайта DAJET – creative memory gallery

## Общая информация
- Название сайта: DAJET – creative memory gallery
- Тип проекта: музыкальный плеер с галереей альбомов
- Язык интерфейса: русский
- Основной язык программирования: JavaScript
- Стили: CSS
- Фреймворки: использует GSAP для анимаций

## Структура проекта

### HTML (index.html)
- Главная страница сайта
- Содержит структуру приложения с:
  - Шапкой с логотипом DAJET и переключателем темы
  - Полем поиска по альбомам и трекам
  - Сеткой альбомов
  - Просмотром выбранного альбома
  - Аудиоплеером внизу страницы
- Подключает несколько CSS-файлов и JS-скриптов

### Стили (CSS файлы)
- style.css - основной файл стилей
- strobe.css, rays.css, effects.css - дополнительные стили для визуальных эффектов
- Поддерживает две темы: dark и lounge
- Использует CSS-переменные для управления цветами
- Реализована адаптивность для мобильных устройств

### JavaScript файлы
- script.js - основная логика плеера (класс DAJETPlayer)
- main.js - основной файл запуска
- themes/theme-manager.js - управление темами
- player.js - логика плеера
- visualizer.js - визуализация аудио
- effects-config.js, effects-manager.js - настройка и управление эффектами
- strobe.js, rays.js - специальные визуальные эффекты
- search.js - функционал поиска
- ui.js - пользовательский интерфейс
- state.js - управление состоянием

### Данные
- data/albums.js - основной файл с информацией о всех альбомах
- albums/ - директория с аудиофайлами и обложками альбомов
- Каждый альбом содержит свои треки в формате .m4a и .jpg

## Альбомы
Проект содержит 6 альбомов:
1. **Album Second** - 14 треков
2. **First Album** - 15 треков
3. **Paradise Lost** - 3 трека
4. **Psychedelic Vibe Lost Century** - 0 треков (пустой)
5. **The third album** - 23 трека
6. **Whisper** - 8 треков

Всего: 63 аудиофайла и соответствующее количество файлов обложек

## Функциональность
- Воспроизведение музыки с возможностью проигрывания, паузы, остановки
- Навигация между треками (предыдущий/следующий)
- Регулировка громкости
- Перемотка трека
- Режимы воспроизведения: повтор одного, повтор всего плейлиста, перемешивание
- Поиск по альбомам и трекам
- Переключение между двумя темами оформления
- Сохранение состояния плеера в localStorage
- Клавиатурные сокращения для управления плеером

## Визуальные эффекты
- Эффект стробоскопа (strobe effect)
- Лучи (rays effect)
- Специальные визуальные эффекты с настройками
- Анимации с использованием GSAP

## Особенности
- Использование современных CSS-приемов (переменные, флексбокс, грид)
- Lazy loading изображений
- Адаптивный дизайн
- Поддержка клавиатурных сокращений
- Интеграция с CDN для библиотек (GSAP)
- Сохранение настроек пользователя

## Технические детали
- Используются современные возможности JavaScript (ES6+)
- Классы для организации кода
- Асинхронные операции для загрузки данных
- Событийная система для взаимодействия компонентов
- Хранение данных в localStorage
