# DAJET Music Player

DAJET — это веб-плеер для музыкального архива с поддержкой гласморфизма и тёмной темы, разработанный для размещения на GitHub Pages. Это солидный архив музыкального творчества BEST — "Галерея памяти".

## 🎯 Особенности

- **Гласморфизм дизайн** — современный стиль с эффектом стекла
- **Две темы** — светлая и тёмная с возможностью переключения
- **Поддержка тысяч треков** — оптимизирован для работы с 4000+ треков
- **Автоматическая генерация плейлистов** — скрипт сканирует папку с музыкой
- **Умный поиск** — по названиям альбомов и треков
- **Полнофункциональный плеер** — воспроизведение, перемешивание, повтор, громкость
- **GitHub Pages готовый** — полностью статический сайт без серверного кода
- **Эффект стробоскопа** — безопасный визуальный эффект синхронизированный с музыкой

## 🌩️ Эффект стробоскопа

### 🔧 Включение/выключение эффекта

Эффект стробоскопа можно включить/выключить с помощью кнопки с молнией (⚡) в плеере. По умолчанию эффект **ВЫКЛЮЧЕН**, и при первом включении появляется предупреждение о безопасности.

### ⚠️ Предупреждение о безопасности

Эффект может вызвать дискомфорт у людей с фоточувствительной эпилепсией. Используйте с осторожностью и обязательно делайте перерывы при длительном прослушивании.

### ⚙️ Настройка интенсивности

Интенсивность эффекта можно настроить программно через JavaScript API:

```javascript
// Установить интенсивность (от 0.05 до 0.3)
StrobeEffect.setIntensity(0.2);

// Переключить режим ('constant' или 'beat-sync')
StrobeEffect.setMode('beat-sync');
```

### 🚫 Отключение через prefers-reduced-motion

Если пользователь установил системное предпочтение `prefers-reduced-motion`, эффект автоматически отключается и не будет отображаться. Это обеспечивает доступность для пользователей, чувствительных к анимациям.

### 🎛️ Технические характеристики

- **Частота пульсации**: 2-4 Гц (безопасный диапазон)
- **Интенсивность**: 5-30% прозрачности
- **Режимы работы**: 
  - `constant`: постоянная мягкая пульсация (2 Гц)
  - `beat-sync`: синхронизация с ритмом музыки (4 Гц)
- **Сохранение состояния**: в localStorage
- **Поддержка тем**: светлая/тёмная (адаптация цвета эффекта)

## 🚀 Быстрый старт

### 1. Установка и настройка

1. Клонируйте или скачайте этот репозиторий
2. Убедитесь, что у вас установлен Python 3.6+
3. Создайте папку `albums` в корне проекта

### 2. Добавление музыки

1. Создайте подпапки в папке `albums` для каждого альбома:
   ```
   albums/
   ├── Album Name 1/
   │   ├── cover.jpg          # Обложка альбома (cover.jpg, folder.jpg или album.jpg)
   │   ├── 01_track_name.mp3  # Аудиофайлы
   │   ├── 02_another_track.mp3
   │   └── 01_track_name.jpg  # Индивидуальная обложка трека (необязательно)
   └── Album Name 2/
       ├── cover.jpg
       ├── 01_song.mp3
       └── 02_music.mp3
   ```

2. Поддерживаемые форматы аудио: `.mp3`, `.wav`, `.flac`, `.ogg`, `.m4a`
3. Поддерживаемые форматы обложек: `.jpg`, `.jpeg`, `.png`, `.webp`

### 3. Генерация плейлистов

1. Откройте терминал в папке проекта
2. Запустите скрипт генерации:
   ```bash
   python generate_playlist.py
   ```

Скрипт автоматически:
- Сканирует папку `albums`
- Находит все альбомы и треки
- Генерирует JS-файлы с метаданными
- Создаёт `data/albums.js` и `data/albums/[AlbumName].js`

### 4. Запуск локально

Откройте `index.html` в браузере или используйте локальный HTTP-сервер:

```bash
# Python 3
python -m http.server 8000

# Затем откройте http://localhost:8000
```

## 🎛️ Функции плеера

### Основные функции:
- **Воспроизведение/пауза** — ▶/⏸
- **Остановка** — ⏹ (сброс прогресса)
- **Следующий/предыдущий трек** — ⏭/⏮
- **Перемотка** — клик по прогресс-бару
- **Громкость** — регулятор громкости
- **Перемешивание** — 🔀
- **Повтор** — 🔁 (три режима: выключен, один трек, всё)

### Режимы повтора:
- **Выключен** — остановка после последнего трека
- **Один трек** — зацикливание текущего трека
- **Все** — переход к первому треку после последнего (по умолчанию)

### Горячие клавиши:
- **Пробел** — воспроизведение/пауза
- **→** — перемотка +5 сек
- **←** — перемотка -5 сек
- **N** — следующий трек
- **P** — предыдущий трек

## 🎨 Переключение тем оформления

- Нажмите на значок луны/солнца в правом верхнем углу
- Тема сохраняется в localStorage между сессиями
- Доступны светлая и тёмная темы

## 📦 Развёртывание на GitHub Pages

1. Создайте новый репозиторий на GitHub
2. Загрузите все файлы проекта в репозиторий
3. Добавьте свою музыку в папку `albums`
4. Сгенерируйте плейлисты:
   ```bash
   python generate_playlist.py
   ```
5. Закоммитьте изменения:
   ```bash
   git add .
   git commit -m "Добавлены альбомы и сгенерированы плейлисты"
   git push origin main
   ```
6. В настройках репозитория (Settings → Pages) выберите:
   - Source: Deploy from a branch
   - Branch: main, folder: /
7. Ваш сайт будет доступен по адресу: `https://yourusername.github.io/repository-name`

## ⚠️ Ограничения GitHub Pages

- **Размер репозитория**: 1 ГБ максимум
- **Рекомендация**: сжимайте аудио до 128-192 kbps MP3 для экономии места
- **Нет серверного кода**: всё работает на клиентской стороне
- **Нет динамического сканирования**: всегда запускайте генератор перед деплоем
