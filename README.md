# DAJET · creative memory gallery

Музыкальная галерея BEST: статический сайт с обложками альбомов, встроенным
плеером, плейлистом, переключением темы оформления и скинов плеера.

**Живой сайт:** https://dj1.ru/ (GitHub Pages, деплой из ветки `main`)

## Как это устроено

```
index.html          разметка страницы
style.css           оформление галереи, тем, панелей
player.css          оформление нижнего плеера, скинов, плейлиста
rays.css            фоновые эффекты (лучи, сфера, частицы)
config.js           настройки: адрес хранилища медиа, целевая громкость
storage.js          безопасная обёртка над localStorage
player.js           логика плеера (Player)
script.js           загрузка library.json, галерея, тема
rays.js             генерация фоновых эффектов
library.json        АВТОГЕНЕРАЦИЯ — альбомы, треки, громкость, тексты песен
CHECKSUMS.sha256    АВТОГЕНЕРАЦИЯ — контрольные суммы файлов коллекции
tools/              проверка целостности, поиск дубликатов, резервная копия
albums/<Альбом>/    аудио (.m4a) + обложки (.jpg/.webp); cover.* — обложка альбома
manifest.json       PWA-манифест
icon.svg            иконка сайта
404.html            страница «не найдено» (GitHub Pages отдаёт её автоматически)
.github/            workflow и скрипт генерации library.json
```

Внешних CDN нет: все скрипты и стили лежат в репозитории, поэтому сайт
не зависит от доступности сторонних сервисов (в том числе из России).

## Возможности плеера

- **Ровно** — выравнивание громкости: треки звучат одинаково ровно, без
  «прыжков» между песнями (уровни посчитаны по EBU R128 и лежат в `library.json`).
  Кнопка отключается, если хочется слышать громкость как в файле.
- **Текст** — текст песни, вшитый в метаданные файла. Кнопка активна только
  там, где текст есть.
- **Продолжить** — сайт помнит последний прослушанный трек и после
  возвращения подставляет его (без автозапуска: браузеры всё равно его блокируют).
- Плейлист, перемешивание, повтор, скины плеера, тёмная/светлая тема,
  управление с клавиатуры (пробел — пауза, стрелки — перемотка и громкость).

## Как добавить альбом

1. Создайте папку `albums/<Название альбома>/`.
2. Положите туда аудио (`.m4a`, `.mp3`, `.wav`, `.ogg`, `.opus`, `.flac`).
3. Обложку альбома назовите `cover.jpg` (или `cover.webp`, `cover.png`).
4. Обложку конкретного трека назовите так же, как трек:
   `Awakening.m4a` → `Awakening.jpg`.
5. Закоммитьте и запушьте — GitHub Actions сам пересоберёт `library.json`
   и перезальёт сайт.

Файлы, которые не похожи на валидное аудио (пустые или обрезанные),
в библиотеку не попадают, а в логе сборки появляется предупреждение.

Локальная пересборка библиотеки (нужен Node.js):

```bash
node .github/scripts/generate-library.js
```

## Инструменты

```bash
# проверить, что файлы коллекции не повреждены и не подменены
node tools/verify-checksums.js

# пересобрать манифест контрольных сумм после правок коллекции
node tools/make-checksums.js

# найти побайтово одинаковые треки (копии в разных альбомах)
node tools/report-duplicates.js

# сделать резервную копию: git-bundle + контрольные суммы
bash tools/make-backup.sh ~/Backups/dajet
bash tools/make-backup.sh /media/usb/dajet --with-media   # + архив самих файлов
```

Резервная копия восстанавливается так:

```bash
git clone ~/Backups/dajet/dajet-2026-10-05.bundle dajet-restored
```

Раз в неделю GitHub Actions сам сверяет файлы с `CHECKSUMS.sha256`
и создаёт issue, если что-то повредилось (workflow «Проверка целостности коллекции»).

## Локальный предпросмотр

Любой статический сервер из корня репозитория, например:

```bash
python3 -m http.server 8080
```

Учтите: `http.server` из Python не поддерживает Range-запросы, поэтому
перемотка аудио в таком предпросмотре работать не будет. При проверке
перемотки используйте сервер с поддержкой Range (например, `npx serve`).

## Тема оформления и скины плеера

- Кнопка ☀/🌙 в шапке переключает тёмную и светлую тему (выбор запоминается).
- Кнопка `Classic / Minimal / Compact` в плеере переключает вид плеера.

## Переезд коллекции на внешнее хранилище

Если аудио перестанет помещаться в лимиты GitHub Pages, откройте
`config.js` и укажите `mediaBase` — адрес хранилища (S3, R2, Selectel,
Bunny). Структура папок на хранилище должна повторять текущую:

```js
mediaBase: 'https://cdn.example.com/dajet/'
```

Больше менять ничего не нужно: и аудио, и обложки будут браться оттуда,
а сайт продолжит работать как обычно.

## Ограничения GitHub Pages

- Опубликованный сайт ограничен ~1 ГБ, репозиторий — 1 ГБ (мягкий лимит),
  трафик — 100 ГБ/мес. Коллекция уже занимает ~665 МБ, поэтому новые
  альбомы лучше выкладывать с битрейтом ~96–128 kbps, а крупные объёмы
  звука — выносить на внешнее хранилище.
- Свои HTTP-заголовки задать нельзя (CSP и прочее настраиваются только
  метатегами).
