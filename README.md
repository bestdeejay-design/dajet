# DAJET - BEST — Галерея памяти

DAJET — это музыкальный плеер с атмосферным дизайном, созданный как "Галерея памяти" с коллекцией альбомов и треков.

## Особенности

- 🎵 Музыкальный плеер с поддержкой альбомов и треков
- 🎨 Две атмосферные темы:
  - **Dark Theme** — "Ночное небо" с анимированными звёздами и космической атмосферой
  - **Lounge Theme** — "У камина" с тёплым огнём и уютной атмосферой
- ⚡ Эффект стробоскопа (безопасный режим)
- 🔍 Поиск по альбомам и трекам
- 🎶 Управление воспроизведением (воспроизведение, пауза, следующий, предыдущий, перемешивание, повтор)
- 🎧 Прогресс воспроизведения и регулировка громкости
- 💾 Сохранение настроек в localStorage
- ♿ Поддержка пользователей с ограниченными возможностями

## Темы

### Dark Theme — "Ночное небо"

Тёмная тема с глубоким ночным небом и анимированными элементами:

- Градиентный фон с космической атмосферой
- Анимированные звёзды с разной интенсивностью мерцания
- Волны/аура с медленным движением
- Плавающие частицы
- Акцентные цвета: фиолетовый (#7c4dff), синий (#00bcd4)
- Гласморфизм для элементов интерфейса

### Lounge Theme — "У камина"

Тёплая тема с атмосферой у костра:

- Тёплый цветовой тон (оранжевый, янтарный, глубокий красный)
- SVG-анимация огня и искр на заднем плане
- Эффект мягкого свечения от центра
- Атмосфера уюта, расслабления и тепла
- Акцентные цвета: оранжевый (#ff6b35), янтарный (#ffb347)

## Управление темами

- Кнопка переключения тем находится в правом верхнем углу
- При переключении темы сохраняется в localStorage
- Плавный переход между темами (300-500ms)
- Темы поддерживают адаптивный дизайн

## Эффект стробоскопа

- По умолчанию **отключен** для безопасности
- Включается через специальную кнопку в плеере
- При первом включении показывается предупреждение о безопасности
- Поддерживает два режима:
  - **Constant** — постоянное мерцание
  - **Beat-sync** — синхронизация с ритмом музыки
- Ограничен безопасной частотой (не более 4 Гц)
- Совместим с новыми темами (Dark и Lounge)
- Поддержка `prefers-reduced-motion` — автоматически отключается при включенной настройке

## Управление плеером

- **Пробел** — воспроизведение/пауза
- **Стрелка влево** — предыдущий трек
- **Стрелка вправо** — следующий трек
- **Стрелка вверх** — увеличение громкости
- **Стрелка вниз** — уменьшение громкости

## Настройки через localStorage

Приложение сохраняет следующие настройки:

- `dajet-theme` — текущая тема ('dark' или 'lounge')
- `volume` — уровень громкости
- `strobeSettings` — настройки стробоскопа
- `strobeWarningShown` — показано ли предупреждение о стробоскопе

## Отключение анимаций

При включенной настройке "Предпочтение уменьшения анимации" (`prefers-reduced-motion`) все анимации, включая стробоскоп, автоматически отключаются для обеспечения комфортного использования.

## Безопасность

- Эффект стробоскопа безопасен и соответствует рекомендациям (частота не превышает 4 Гц)
- При включении показывается предупреждение о возможных рисках для людей с фоточувствительной эпилепсией
- Существует возможность отключения эффекта в один клик
- Поддержка `prefers-reduced-motion` для автоматического отключения анимаций
