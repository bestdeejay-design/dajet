# DAJET Music Player

**DAJET** — это современный музыкальный плеер с галереей альбомов, реализованный на чистом JavaScript без использования каких-либо фреймворков. Проект разработан для размещения на GitHub Pages с автоматической генерацией плейлистов через GitHub Actions.

## 🎵 Особенности

- **Чистый JavaScript** — без использования фреймворков
- **Гласморфизм дизайн** — стильный интерфейс с эффектом стекла
- **Две темы** — тёмная и "у камина" с анимированными SVG-фонами
- **Автоматическая генерация плейлистов** — через GitHub Actions
- **Визуализация аудио** — синхронизированная с воспроизведением
- **Поиск по альбомам и трекам** — с фильтрацией
- **Сохранение состояния** — воспроизведение восстанавливается при перезагрузке

## 🚀 Установка и настройка

### 1. Клонирование репозитория

```bash
git clone https://github.com/your-username/dajet-music-player.git
cd dajet-music-player
```

### 2. Добавление музыкальных файлов

Поместите свои альбомы в папку `albums/`. Каждый альбом должен быть в отдельной папке:

```
albums/
├── First Album/
│   ├── cover.jpg
│   ├── track01.mp3
│   ├── track02.mp3
│   └── ...
├── Second Album/
│   ├── folder.jpg
│   ├── song1.wav
│   ├── song2.flac
│   └── ...
└── ...
```

### 3. Локальная генерация плейлистов

Если вы хотите сгенерировать плейлисты локально:

```bash
node generate-playlist.js
```

Это создаст файлы в папке `data/`, которые будут использоваться плеером.

### 4. Настройка GitHub Pages

1. Перейдите в настройки репозитория (Settings)
2. Прокрутите вниз до "Pages"
3. Выберите "Deploy from a branch"
4. Выберите ветку `main` и папку `/root`
5. Нажмите "Save"

## ⚙️ Конфигурация

Файл `config.json` позволяет настроить:

- `albumsFolder` — папка с альбомами (по умолчанию: "albums")
- `outputFolder` — папка для генерации данных (по умолчанию: "data")
- `defaultArtist` — исполнитель по умолчанию (по умолчанию: "BEST")
- `supportedAudio` — поддерживаемые аудиоформаты
- `supportedImages` — поддерживаемые форматы изображений
- `coverNames` — возможные имена файлов обложек
- `sortAlbums` — способ сортировки альбомов ("name" или "year")
- `sortTracks` — способ сортировки треков ("name")

## 🎨 Темы

DAJET поддерживает две темы:

1. **Тёмная** — современная тёмная тема с фиолетово-синими акцентами
2. **Lounge** — тёплая тема в стиле "у камина" с оранжево-янтарными акцентами

Переключение между темами происходит автоматически или вручную через интерфейс.

## 🎼 Использование

1. Откройте главную страницу — отобразится сетка альбомов
2. Нажмите на альбом, чтобы открыть список треков
3. Нажмите на трек, чтобы начать воспроизведение
4. Используйте панель в нижней части для управления воспроизведением
5. Используйте поиск для быстрого поиска альбомов и треков

### Управление воспроизведением

- **Воспроизведение/пауза**: Кнопка ▶️ / ⏸️
- **Следующий трек**: Кнопка ⏭️
- **Предыдущий трек**: Кнопка ⏮️
- **Перемотка**: Перетаскивание ползунка прогресса
- **Громкость**: Ползунок громкости

### Дополнительные функции

- **Повтор**: Переключение между режимами "все", "один", "выкл"
- **Перемешивание**: Включение/выключение случайного порядка
- **Визуализация**: Включение/выключение аудио-визуализации
- **Эффекты**: Настройка визуальных эффектов (стробоскоп, лучи)

## 🔧 Разработка

1. Все функции разделены на модули для удобства разработки

Проект использует CSS-переменные для управления темами:

```css

  --bg-primary: #0a0a0f;
  --bg-secondary: #12121a;
  --text-primary: #ffffff;
  --accent-primary: #7c4dff;
}

:root[data-theme="lounge"] {
  /* Теплые тона для lounge темы */
  --bg-primary: #1a0f0a;
  --bg-secondary: #2a1810;
  --text-primary: #f5e6d3;
  --accent-primary: #ff6b35;
}
```

## 🚀 Деплой на GitHub Pages

Проект автоматически развернётся на GitHub Pages при пуше в ветку `main`. GitHub Actions автоматически:

1. Запустит скрипт `generate-playlist.js`
2. Сгенерирует новые плейлисты
3. Закоммитит изменения в репозиторий
4. Обновит GitHub Pages

Для этого используется workflow в `.github/workflows/generate-playlist.yml`.

## 🛠️ Технические детали

### Автогенерация плейлистов

Скрипт `generate-playlist.js` анализирует папку `albums/` и создаёт:

1. `data/albums.js` — список всех альбомов
2. `data/albums/[AlbumName].js` — треки конкретного альбома

Каждый сгенерированный файл содержит метаинформацию об альбоме и треках.

### Управление состоянием

Класс `PlayerState` управляет всеми аспектами состояния плеера:

- Текущий трек и альбом
- Состояние воспроизведения
- Громкость
- Выбранная тема
- Настройки эффектов

Состояние сохраняется в localStorage и восстанавливается при перезагрузке.
