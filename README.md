# DAJET Music Player

DAJET - это веб-плеер для музыкального архива с гласморфическим дизайном и поддержкой темной/светлой темы. Создан для просмотра и воспроизведения музыкальных альбомов с возможностью поиска, перемешивания и управления воспроизведением.

## 🎯 Особенности

- **Гласморфизм**: Современный дизайн с эффектом стекла
- **Две темы**: Светлая и темная тема с переключением
- **Поиск**: Быстрый поиск по альбомам
- **Управление**: Полнофункциональный плеер с повтором, перемешиванием, громкостью
- **Горячие клавиши**: Пробел (воспроизведение/пауза), стрелки (перемотка), N/P (след./пред.)
- **Адаптивность**: Корректно отображается на мобильных устройствах
- **Офлайн**: Работает полностью автономно

## 🔧 Установка и настройка

### 1. Клонирование репозитория

```bash
git clone <ваш-репозиторий>
cd dajet-music-player
```

### 2. Подготовка музыкальных файлов

Создайте папку `albums` и поместите в неё подпапки с альбомами:

```
albums/
├── Album1/
│   ├── cover.jpg          # Обложка альбома (cover, folder, album)
│   ├── track01.mp3        # Аудиофайл
│   ├── track01.jpg        # Индивидуальная обложка трека (опционально)
│   ├── track02.mp3
│   └── ...
└── Album2/
    └── ...
```

#### Поддерживаемые форматы:

**Аудио:** `.mp3`, `.wav`, `.flac`, `.ogg`, `.m4a`
**Изображения:** `.jpg`, `.jpeg`, `.png`, `.webp`

#### Имена обложек альбома:
- `cover.jpg`
- `folder.jpg` 
- `album.jpg`

### 3. Генерация плейлистов

Запустите скрипт генерации:

```bash
python generate_playlist.py
```

Скрипт создаст:
- `data/albums.js` - список всех альбомов
- `data/albums/*.js` - треки для каждого альбома

## ⚙️ Настройка конфигурации

Отредактируйте `config.json` для настройки параметров:

```json
{
  "albumsFolder": "albums",
  "outputFolder": "data", 
  "defaultArtist": "BEST",
  "supportedAudio": [".mp3", ".wav", ".flac", ".ogg", ".m4a"],
  "supportedImages": [".jpg", ".jpeg", ".png", ".webp"],
  "coverNames": ["cover", "folder", "album"]
}
```

## 🚀 Запуск локально

Для локального тестирования используйте простой HTTP-сервер:

### Python (встроен):
```bash
python -m http.server 8000
```

### Node.js:
```bash
npx serve .
```

Затем откройте `http://localhost:8000` в браузере.

## 🎮 Управление плеером

### Интерфейс:
- **Клик по альбому** → Просмотр списка треков
- **Клик по треку** → Воспроизведение
- **Кнопка "Назад"** → Вернуться к списку альбомов
- **Поиск** → Поиск по названию альбома

### Кнопки плеера:
- **▶ / ⏸** - Воспроизведение/пауза
- **⏮** - Предыдущий трек (или начало текущего если >3сек)
- **⏭** - Следующий трек
- **🔁** - Переключение режима повтора (none → all → one)
- **🔀** - Перемешивание треков

### Горячие клавиши:
- **Пробел** - Воспроизведение/пауза
- **→** - Перемотка +5 секунд
- **←** - Перемотка -5 секунд
- **N** - Следующий трек
- **P** - Предыдущий трек

### Регулировка:
- **Ползунок громкости** - Изменение уровня громкости
- **Клик по прогресс-бару** - Перемотка к указанному времени

## 🎨 Переключение темы

Кнопка в правом верхнем углу позволяет переключаться между светлой и тёмной темой. Выбранная тема сохраняется в localStorage.

## ⚠️ Ограничения GitHub Pages

- **Размер репозитория**: 1 ГБ (рекомендуется сжимать аудио до 128-192 kbps MP3)
- **Нет серверного кода**: Всё работает на клиентской стороне
- **Нет динамического сканирования**: Используйте скрипт генерации перед деплоем
- **Файлы только внутри репозитория**: Все аудио и изображения должны находиться в репозитории

- **Совместимость**: Работает в современных браузерах (Chrome, Firefox, Safari, Edge)
